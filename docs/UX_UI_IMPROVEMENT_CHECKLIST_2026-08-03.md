# 원클릭클래스 UX/UI 개선 체크리스트

기준일: 2026-08-03
목표: 콘텐츠를 가진 강사가 `첫 강의 만들기 → 미리보기 → 게시 → 공유`까지 막힘없이 도달하고, 학습자는 공유 링크에서 신청과 학습을 자연스럽게 이어가도록 한다.

## 1. 이번 개선의 기준

- [x] 랜딩 페이지는 사용자 요청에 따라 기존 구성과 메시지를 유지한다.
- [x] 신규 강사에게 빈 운영 지표보다 첫 강의를 만드는 행동을 먼저 제시한다.
- [x] 동작하지 않는 기능은 실제 기능처럼 강조하지 않는다.
- [x] 페이지 이동 후에도 사용자가 원래 가려던 주소와 작업 맥락을 보존한다.
- [x] 데스크톱과 모바일에서 행동 이름·우선순위·조작 방식을 일관되게 유지한다.

## 2. 정보 구조와 사용자 흐름

### 랜딩 페이지 — 기존안 유지

- [x] 기존 Hero, 강의 만들기, 학습자 경험, 강사 홈, 운영 섹션을 유지한다.
- [x] 기존 `무료로 시작하기 → 회원가입` 전환 경로를 유지한다.
- [x] 기존 브랜드 컬러와 랜딩 전용 레이아웃을 유지한다.
- [x] 이번 검토에서 추가했던 YouTube 즉시 입력 폼과 전환형 Hero는 반영하지 않는다.
- [ ] 실제 강사 사례를 `원본 콘텐츠 → 생성 결과 → 첫 신청` 형식으로 추가한다.
  - 준비물: 사용 허가를 받은 사례, 성과 수치, 강사 또는 채널 정보
- [ ] 가격·무료 범위·수수료·정산 주기 섹션을 추가한다.
  - 차단 사유: 실제 요금제, 결제 수수료, 지급 주기 정책 확정 필요

### 인증과 작업 복원

- [x] 기존 카카오·네이버·Google OAuth 로그인 방식을 주요 진입 경로로 유지한다.
- [x] 이메일 로그인은 보조 경로로 제공하고 기존 OAuth 흐름과 경쟁하지 않게 한다.
- [x] 로그인 홍보 문구를 YouTube 전용이 아닌 영상·문서 등 다양한 콘텐츠 기준으로 정리한다.
- [x] 로그인 마케팅 영역과 폼의 중복 H1을 정리한다.
- [x] 인증이 필요한 화면 진입 시 `pathname + query + hash`를 로그인 후 복원한다.
- [x] 가입 약관을 실제 checkbox와 별도 `보기` 버튼 구조로 교정한다.
- [x] 이메일·비밀번호·이름 입력에 적절한 `type`과 `autocomplete`을 제공한다.

## 3. 강사 활성화와 클래스 생성

- [x] 클래스가 없는 신규 대시보드는 KPI 대신 첫 강의 시작 화면을 보여준다.
- [x] 신규 대시보드의 주 행동은 `YouTube 링크로 시작`, 보조 행동은 `다른 방식으로 만들기`로 제한한다.
- [x] `YouTube 링크로 시작`은 강의 만들기 자료 선택 단계로 바로 연결한다.
- [x] 영상 파일·문서·직접 작성 등 다른 제작 방식도 같은 화면에서 명확하게 선택할 수 있게 한다.
- [x] 모바일 신규 대시보드에도 같은 활성화 흐름을 제공한다.
- [x] 기존 5단계 구조, 자동 저장, 자료 다시 선택, 게시 확인 흐름을 유지한다.
- [x] 모바일 YouTube URL 입력의 조작 높이를 44px 이상으로 맞춘다.
- [x] 미리보기 일정 카드에서 날짜와 시간을 직접 수정하고 완료·취소·유효성 검사를 제공한다.
- [ ] 파일 업로드 전 용량 제한과 지원 형식을 입력 영역 가까이에서 명확히 안내한다.
- [ ] YouTube 메타데이터 확인 실패 시 원인별 메시지와 재시도 행동을 분리한다.

## 4. 학습자 전환 흐름

- [x] 모바일 공개 페이지에서 신청 폼이 보이면 하단 고정 CTA를 숨긴다.
- [x] 고정 CTA와 실제 제출 버튼이 동시에 경쟁하지 않게 한다.
- [x] 관심 클래스 저장 버튼을 공개 페이지의 주요 행동과 같은 영역에 제공한다.
- [x] 관심 저장 상태와 실패 메시지를 접근성 속성으로 전달한다.
- [x] 학습 진도 애니메이션을 레이아웃 변경이 적은 `transform` 방식으로 개선한다.
- [ ] 가격 근처에 환불 기준과 결제 보호 안내 링크를 제공한다.
  - 차단 사유: 환불·결제 정책과 연결할 실제 문서 경로 확정 필요
- [ ] 강사 프로필과 콘텐츠 소유권 정보를 공개 페이지에서 강화한다.
  - 준비물: 표시 가능한 강사 데이터와 운영 정책 정의 필요

## 5. 디자인 일관성·반응형·접근성

- [x] 새 대시보드 활성화 카드는 기존 surface, radius, shadow 토큰을 사용한다.
- [x] 보조 문구 대비를 높이고 기존 텍스트 토큰에 맞춘다.
- [x] 로그인·회원가입의 주요 링크와 약관 조작 영역을 최소 44px로 맞춘다.
- [x] 입력 오류와 저장 실패를 `role="alert"` 또는 `role="status"`로 전달한다.
- [x] 버튼 문구와 화살표 아이콘 체계를 클래스 생성 흐름에서 통일한다.
- [ ] 반복되는 hex 값을 상태·브랜드·배경·테두리 토큰으로 단계적으로 교체한다.
  - 원칙: 기능 단위 수정 때 함께 교체하며 대규모 일괄 치환은 피한다.

## 7. 측정 지표

- `가입 CTA 클릭률`: 랜딩 방문 중 회원가입 진입 비율
- `가입 → 첫 생성 시작률`: 가입 후 강의 만들기를 시작한 비율
- `자료 시작 경로 선택률`: YouTube·영상 파일·문서·직접 작성 중 선택한 경로의 비율
- `첫 미리보기 도달 시간`: 생성 시작부터 미리보기까지 걸린 시간
- `첫 게시율`: 신규 강사가 첫 세션 또는 24시간 내 클래스를 게시한 비율
- `첫 공유율`: 게시 후 링크 복사·공유·QR 중 하나를 완료한 비율

분석 이벤트 이름과 개인정보 처리 기준은 분석 도구가 확정될 때 별도 명세한다.

## 8. 유지해야 하는 설계

- [x] 기존 랜딩 페이지의 콘텐츠와 시각 구성
- [x] 단계별 클래스 생성 구조와 진행률
- [x] 자동 저장, 입력 보존, 오류 필드 포커스
- [x] 자료 다시 선택과 직접 작성 대안
- [x] 게시 확인과 게시 후 공유·QR 흐름
- [x] 학습자의 공유 링크 중심 접근과 무계정 재입장
